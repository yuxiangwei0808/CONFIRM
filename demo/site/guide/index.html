How to read these examples

Synthetic measurements. The three interactive examples use independent samples generated with fixed seeds. Measurements are in arbitrary units. Plots show 180 observations from each 600-observation cohort; analyses use all 600.

Reporting support. Supported means the selected reporting requirements passed. The standard comparison illustrates fixed requirements applied to the same results. Choose the reporting standard before running a new analysis.

Computed evidence. The plan, statistical results, and checks are exported from CONFIRM. The visual guide adds explanations and plots. A complete analysis record is available for each example.
